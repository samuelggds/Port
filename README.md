Os projetos independentes são identificados como tal. A imagem da GastroNexa é uma prévia exportada do Figma, não uma captura de produção. Não são apresentados números não verificados de receita, usuários ou experiência profissional.

## Como visualizar

Abra `index.html` no navegador ou execute `python -m http.server 8000` na raiz e abra `http://localhost:8000`.

Não há dependências de build nem JavaScript obrigatório.

## Publicação pelo GitHub Pages

Após revisar e fazer merge do PR para a branch `master`:

1. Abra **Settings > Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `master`, pasta `/ (root)`, e salve.
4. Confira o endereço publicado pela plataforma. Não pressupor que um endereço já está ativo.
